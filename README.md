# KGHarvest-endstone

Harvesting enhancements for KG Survival.

## Requirements

- Endstone 0.11.x
- Minecraft Bedrock Dedicated Server

## Features

### Tree Capitator

Tree Capitator allows players with the required permission to harvest connected logs at once.

Activation:

- Hold an axe.
- Sneak.
- Break a log.

## Permission

```text
kgharvest.treecapitator
